# Application Tableau de bord

Une application Flutter affichant une liste de données sous forme de tableau responsive.

## Fonctionnalités
- Affichage de données sous forme de `DataTable` sur les écrans larges (ordinateur, tablette).
- Affichage des mêmes données sous forme de liste de cartes sur les écrans étroits (mobile) pour une meilleure lisibilité.
- Support du mode sombre / clair en fonction du thème du système.

## Lancer l'application
Pour lancer l'application en mode développement :
```bash
flutter run
```

## Structure
- L'application utilise `LayoutBuilder` pour détecter la largeur de l'écran et adapter son interface.
